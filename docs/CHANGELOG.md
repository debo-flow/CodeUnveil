# Changelog

## [1.0.0] - 2026-11-02
### CodeUnveil Stable Release

CodeUnveil is now fully out of development (Milestones 1 - 25 integrated). 

#### Added
- **M25 Integration**: Stabilized the Monolithic Orchestrator, added `pyproject.toml` PEP 517 build system, and a `codeunveil` CLI entrypoint.
- **M24 QA Engine**: Added self-diagnosing integrity tests, GitHub Actions CI/CD matrix, and strict `ruff`/`mypy` linting rules.
- **M23 Plugins**: Added Headless FastAPI and Custom SDK Python Plugins.
- **M22 Workspaces**: Added persistent JSON databases for Project state and Audit History mapping.
- **M21 Pro UI**: Fully rebuilt Streamlit frontend with SPA-routing, Global Commands, and Streamlit-Ace syntax highlighting.
- **M14-M20 Deep Analysis**: Control Flow Deflattening, Z3 Symbolic Execution, Semantic Type Inference, and SHA-256 Pipeline Caching.
- **M1-M13 Core**: The underlying static deobfuscation algorithms (Strings, DCE, CFG, Obfuscator detection, Renaming, Validation).
